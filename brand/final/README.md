# Akriven logo

Selected direction: **Aperture**, concept 02.

The mark combines a schema/contract sheet, a geometric `A`, and a horizontal
verification channel. The acid segment is the decision point where an admitted
tool call exits the checkpoint.

## Files

- `akriven-mark.svg`: primary mark for light surfaces
- `akriven-mark-reversed.svg`: reversed mark for dark surfaces
- `akriven-lockup.svg`: primary horizontal lockup

## Palette

- Akriven Ink: `#11131A`
- Signal Acid: `#DDFE52`
- Porcelain: `#F5F4EE`
- Verification Mint: `#72E6B1`
- Fault Coral: `#FF6B5E`

Use only Ink, Signal Acid, and Porcelain in the logo. Mint and Coral are product
status colors and should not be introduced into the mark.

The lockup currently uses a system-font wordmark for portability during design
development. Convert the approved wordmark to outlines before distributing final
press or trademark master files.
